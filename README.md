# AI-Powered Expense Categorization System

This project automatically classifies expense descriptions into predefined categories using
Natural Language Processing and Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Probability Calibration
- Gradio UI
- Google Colab

## Features
- Automatic expense categorization
- Confidence-based decision (Accept / Review)
- Manual correction and logging
- Monthly and category-wise analytics dashboard

## How to Run
1. Open the notebook in Google Colab
2. Mount Google Drive
3. Run all cells in sequence
4. Launch the Gradio interface
